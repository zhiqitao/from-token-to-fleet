Ch19 gives L_E2E(T=3) ≈ 9.3 s (Table 19-1: ~8.6 s base + ~660 ms added orchestration); Ch17 §8 derives the same T=3 agentic request at W ≈ 13.8 s (1.08 s prefill of 12,095-token context + 495 generated tokens × ~25 ms = ~12.4 s decode + ~0.4 s tool latency).
