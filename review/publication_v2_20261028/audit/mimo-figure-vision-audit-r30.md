# MiMo 图表视觉复审 — R30（印刷尺寸 145 dpi 独立二次意见）

范围：`work/accelerated_external_review_proof_r30/render/build/from-token-to-fleet-v20260913.pdf`（425 页）。
优先 7 图（16.1 / 19.2 / 19.3 / 20.1 / 21.1 / 22.1 / 26.2）+ 新再生成 8 图（2.2 / 7.5 / 10.1 / 12.1 / 23.1 / 25.1 / A.2 / A.4），共 **15 图全部实检**。

方法与证据：
- 每图所在页以 **145 dpi（= 实体印刷尺寸，6×9 in，1233×1595 px）** 整页渲染 + 图区裁切（不放大），`vision_analyze` 直接读印刷尺寸图；PNG 存 `scratch/mimo_fig_r30/`（`p<页>_<图>_full.png` / `_fig.png`，`zoom_*.png` 为 290 dpi 结构复核专用）。
- 字号：矢量图用 pymupdf span 实测（图区内最小值）；栅格图（19.2/19.3/20.1，390–400 dpi 嵌入）文字不可提取，用**墨迹行高 ÷ px-per-pt** 推算（含升部+降部的行 ≈ 1 em）。
- 灰度/对比度：程序计算相对亮度与 WCAG 对比度；影线/箭头几何用 drawing rect 与线段交点解算。
- **注意**：vision 的"pt 估计"系统性偏小（把 cap height 当字号），凡与程序实测冲突处一律以程序实测为准；下文标注 确认 / 不确定 / 否证。
