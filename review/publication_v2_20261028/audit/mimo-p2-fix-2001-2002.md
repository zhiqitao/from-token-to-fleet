### MiMo-2002（Ch25 §8 印刷 p348）

- 2.62 MB/token = 2 × n_layers(80) × H_kv × D_head × 2 B ⇒ H_kv × D_head = 8192。
- 书内约定 D_head = 128（Ch7 GQA 例、Ch4 `K/V width = hidden_dim = 8192`）⇒ **H_kv = 64**。
- 若为 32 KV heads：2×80×(32×128)×2 = 1,310,720 B = **1.31 MB/token**（恰为一半，与同句 2.62 矛盾）。
- 64 KV heads：2×80×(64×128)×2 = 2,621,440 B = **2.62 MB = 2.5 MiB** ✓ 与 Ch7 `64 K/V per token`、Ch4 `K/V width = hidden_dim = 8192` 一致。
- 修复取向：保留 2.62 MB（全书常数，Ch7/Ch15/Ch17/Ch25 证据标签均依赖），头数 32 → **64**。
