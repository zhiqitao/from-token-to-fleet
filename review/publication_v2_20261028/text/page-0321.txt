figure 26.1: Workload fingerprints on the six axes. Provenance note: the six axes (context length, 
traffic, quality required, cost sensitive, latency sensitive, output tokens) are subjective normalized 
scores (0–1) that characterize the canonical scenario’s workload (Ch 4) — they are a workload-
fingerprint view, distinct from Ch 4’s six architectural-decision dimensions (Quality, Traffic, Token 
profile, Latency, Economic, Operational). The bars are a visualization of the characterization, not 
a benchmark. Each bar is an authored 0–1 intensity score for that family on that axis — there is 
no min–max rescaling of measured data. In axis order (context length, traffic, quality, cost, latency, 
output tokens) the scores are long-context RAG Q&A 0.95 / 0.20 / 0.70 / 0.55 / 0.40 / 0.45, chat 0.35 / 
0.95 / 0.50 / 0.75 / 0.90 / 0.55, batch 0.55 / 0.60 / 0.30 / 0.85 / 0.35 / 0.90 — the same table is carried 
in the figure’s generator script (render/fig_ch26_fingerprint.py); the archetypes are reference 
points, not measured clusters.
