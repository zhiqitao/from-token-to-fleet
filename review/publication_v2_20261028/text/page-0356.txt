Reference-geometry convention. Any isolated per-token KV or memory figure in this book 
(e.g. ‘2.62 MB/token’, the raw FP8 ‘1.31 MB/token’, or a GB figure) refers to the canonical reference 
geometry — full multi-head attention (MHA), 80 layers, hidden width 8192, BF16/FP16 — unless the 
surrounding text or caption names a different geometry. This is the deliberately pessimistic upper 
bound from Ch. 1/7. It is not a typical 70B-model KV footprint: a real 70B model may use GQA, MLA, 
or hybrid attention, which reduce KV per token, so an architecture-specific figure must be derived 
for that model’s own attention shape rather than inheriting the MHA number. A decimal GB/binary 
GiB distinction is stated wherever a precise mount depends on it; where only an order of magnitude 
matters, the base is given explicitly.
Two conventions apply throughout. (1) “KV raw per token” always means the un-allocated array 
product, stated in base-2 (MiB) and base-10 (MB) as appropriate; “KV allocated” or “measured 
footprint” includes the metadata and cache-block overhead. Do not conflate them. (2) A precision 
adjective is always attached to its subject (“FP16 weights” vs “FP8 KV”), never implied. (3) An 
architecture-specific advantage (GQA ∼8×, MLA, hybrid) is a sensitivity for that configuration only 
and is not inherited by a different model.
