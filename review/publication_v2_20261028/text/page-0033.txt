figure 2.1: The canonical end-to-end inference pipeline, in three bands. PREFILL (top) is the one-shot 
parallel pass over the whole prompt; it populates the persistent KV cache and is the dominant 
contributor to TTFT (time to first token — though TTFT also includes queueing, preprocessing, and 
transport, so model prefill latency is a component of, not identical to, user-observed TTFT). DECODE 
(bottom) is the single-token autoregressive loop, measured by TPOT/ITL (time per output token / 
inter-token latency); each step reads the cached K/V, appends the new K/V, and samples the next 
token. The green initialize path seeds the loop with the first sampled token. The three bands and the 
single PERSISTENT KV CACHE box are conceptual groupings for teaching, not runtime components: 
a real serving stack has per-layer, per-request KV state and no literal “prefill band” object.
