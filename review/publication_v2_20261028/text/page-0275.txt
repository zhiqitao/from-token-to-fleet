21.4. Measurement
The factory is only as trustworthy as its gates. We measure four things continuously:
1. Gate pass rate / false-promotion rate — how often a gated change later regresses in 
production; a rising value means the evaluation suite is losing fidelity.
2. Canary-to-production time and rollback time — the speed of promotion and escape; both 
should be minutes, not days.
3. Model freshness / data staleness — time since the retrieval corpus or model was last validated; 
drift detection feeds the retraining decision.
4. MTTR for a bad release — mean time to detect + rollback; the factory’s core reliability 
number.
