Sources, Method, and Reproducibility
This handbook marks every number with an evidence label so a reader never has to guess the 
provenance, the epistemic status, or the measurement status of a figure. The book publishes exactly 
one authoritative taxonomy, and it has three orthogonal axes: Axis 1 source provenance (where 
the number comes from), Axis 2 epistemic status (what the number claims to be), and Axis 3 
measurement status (how far the number has climbed the measurement-status hierarchy). Labels 
of the form [provenance][epistemic-status] combine one item from each of Axes 1 and 2; the 
Axis-3 measurement status rides with that pair (e.g. [LAB][MEASURED]) or stands alone (e.g. a bare 
[ANALYTICAL]). The axes are orthogonal — each answers a different question, so an item from one 
axis never substitutes for an item from another, and the measurement-status hierarchy below is Axis 
3 of this taxonomy, not a second, competing scheme.
Axis 1 — Source provenance: where the number comes from.
• [1P] First-party / primary source. A vendor technical report, model card, or official docu­
mentation. These are the model’s own stated parameters, benchmarks, and limits.
• [canonical scenario] The book’s own internally-defined canonical workload and model 
(Ch 4, Table 4-2). This is an internal source the book sets up so its arithmetic is anchored and 
reproducible; it is author-defined, not external first-party evidence. Used to distinguish ”where 
this number comes from inside the book” from ”[1P]” (a real vendor source).
• [2°] Secondary source. A third-party measurement, survey, or synthesis (e.g. an independent 
benchmark or a community write-up). Requires independent verification.
• [LAB] Measured on the author’s own hardware. These are home-lab measurements, not 
production hardware, and are used to illustrate mechanisms and orders of magnitude.
• [ILLUSTRATIVE] A worked-example or scenario input chosen to demonstrate a calculation, 
not a reported measurement. It is a number we assumed so the arithmetic would be concrete.
Axis 2 — Epistemic status: what the number claims to be.
• [FACT] Stated by the source as a fact (e.g. a parameter count or a vendor benchmark).
