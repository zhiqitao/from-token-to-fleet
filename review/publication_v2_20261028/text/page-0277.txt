The AI Factory: Turning Inference Into an Industrial Process
figure 21.1: The AI Factory promotion pipeline, showing the model lifecycle layer named in the 
chapter opener (the model lifecycle, the serving pipeline, and the operations loop). Each stage has an 
explicit promotion gate (a measured metric that must PASS before the next stage begins): (1) Data 
→ gate: src valid; (2) Train → gate: cost ok; (3) Eval → gate: qual ok; (4) Canary → gate: health 
ok; (5) Observe → gate: TTFT ok; (6) Promote → gate: cost ok; (7) Serve — the loop’s output, no 
gate of its own. Failure path: any gate FAIL rolls back to the last-known-good and re-validates. 
Feedback loop: production feedback → data/evaluation, each cycle re-gated. Every promotion is a 
PASS/FAIL decision on a measured metric, not a hand-off — the gates are the mechanism that makes 
“promotion” a decision, not a hope.
The model lifecycle: data → train → eval → canary → observe → promote → serve, every transition 
re-gated PASS/FAIL with rollback to last-known-good, and a production feedback loop back to 
data/evaluation.
