• GQA — grouped-query attention; MQA — multi-query attention; MHA — multi-head attention; 
MLA — multi-head latent attention: a compressed per-token KV (K/V stored in a low-rank 
latent space), so KV per token still grows with context but at fewer bytes/token than full MHA 
(Ch 1, 8; App. A).
• APC / RadixAttention / prefix cache — caching of shared prompt prefixes to avoid recom­
putation.
• prompt caching — the broader system/provider term; the book uses it to mean reusing the KV 
of a shared prompt prefix across requests, so it is not a separate mechanism from prefix caching 
above (Ch 2) — the provider-facing name for the same reuse, kept as its own entry because 
providers document and bill it as a feature.
• cache hit / miss — a cache hit serves a request (or a shared prefix) from cached state without 
recomputing it; a miss must be computed (or re-prefilled); the hit ratio (hits ÷ requests) is the 
FACT that the prefix- and semantic-cache arithmetic starts from (Ch 15, 19, 26).
• TTL — time-to-live: how long a cached entry stays valid before it must be refreshed or evicted; 
the semantic response cache uses a 5-min TTL, and its hit ratio is measured at TTL=T (Ch 26).
• LRU — least-recently-used: the eviction policy that discards the least recently used cache entry 
first (Ch 26, Table 26-2).
• HBM — high-bandwidth memory: the large, relatively slow-capacity memory attached to a 
GPU (distinct from fast on-chip SRAM).
• arithmetic intensity — FLOPs moved per byte read from memory (FLOP/byte); the quantity 
that determines whether a kernel is compute-bound or memory-bound.
• MoE — mixture of experts: a sparse model that routes each token to a subset of expert layers, 
cutting compute-per-token without reducing the parameter count or (necessarily) the KV 
cache.
Parallelism and flows
• TP — tensor parallelism; PP — pipeline parallelism; DP — data parallelism; EP — expert 
parallelism; FSDP — fully sharded data parallelism (shards the model weights, gradients and 
optimizer state across ranks, reducing per-rank memory vs full-replica DP); CP — context 
parallelism (shards the sequence dimension across ranks when a single context is too long for 
one rank).
• all-reduce — the collective that aggregates (e.g. sums) a tensor across ranks so every rank 
ends with the same reduced value; used to share gradients, activations, or states.
• RQO — Reasoned Quality Optimization: a structured process that optimizes a quality metric 
(e.g. answer relevance) by iterating over prompts, retrieval, and model choices, rather than 
treating quality as a fixed model property (Ch 25 §6).
