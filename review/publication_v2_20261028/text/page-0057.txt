figure 3.1: Dense vs MoE parameter allocation and KV cache behavior. Controlled comparison: same 
attention geometry, same context and cache dtype — so the KV footprint is identical — while weight 
residency (140 GB dense vs ~94 GB for the ~47B MoE challenger) and the active-compute fraction 
(~100% vs ~30%) both differ. Schematic, not to scale. An MoE model that also uses GQA or a different 
attention mechanism is a different comparison (Ch. 7).
Parameter-activation contrast. A dense 70B activates all 70B parameters per token (residency ≈ 140 GB, 
KV grows linearly with context). An 8-expert MoE still stores its full expert set as resident weights (not 
shown to scale), but only the top-2 (~14B) are active per token (active compute footprint ≈ 28 GB). KV 
cache growth with context is identical to dense — attention still processes every token.
