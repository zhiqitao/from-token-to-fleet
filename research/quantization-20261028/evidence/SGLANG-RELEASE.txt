[#41444](https://github.com/sgl-project/sglang/pull/41444)\r\n\r\n## Breaking Changes & Upgrade Notes\r\n\r\n* **SGLang requires Python 3.11 or newer.** On Python 3.10, `pip install sglang` does not fail; it resolves to the last release that supported 3.10. Move to Python 3.11+ (for example off the Ubuntu 22.04 system Python) to get this and later releases: [#43021](https://github.com/sgl-project/sglang/pull/43021)\r\n* **`--enable-dp-attention` is deprecated; use `--attn-dp-size N`.** `--dp-size` now counts model replicas only. The old `--dp-size N --enable-dp-attention` still resolves to `--attn-dp-size N` with a warning; combining replicas with attention DP, or passing both spellings, is rejected at startup: [#41818](https://github.com/sgl-project/sglang/pull/41818). Under DeepSeek context parallelism, `--dp-size N` still means attention DP but now warns and will be rejected after 2026-12-31: [#42348](https://github.com/sgl-project/sglang/pull/42348)\r\n* **`--disaggregation-decode-host-receive-threshold` flips its encoding.** `1` (the new default) disables host receive and `0` now means always receive on host. Configurations that passed `0` to disable it must pass `1`: [#43407](https://github.com/sgl-project/sglang/pull/43407)\r\n* **`ChunkCache` is removed.** With `--disable-radix-cache`, full-attention, hybrid-SWA and Mamba models run `UnifiedRadixCache` in disabled mode and pure-SWA models run `PureSWARadixCache` ([#43198](https://github.com/sgl-project/sglang/pull/43198), [#43199](https://github.com/sgl-project/sglang/pull/43199), [#43200](https://github.com/sgl-project/sglang/pull/43200), [#42354](https://github.com/sgl-project/sglang/pull/42354), [#43201](https://github.com/sgl-project/sglang/pull/43201)). Streaming sessions now start only on `UnifiedRadixCache`; pure-SWA, FlexKV and plugin tree caches fail at startup with a \"not verified\" error ([#42295](https://github.com/sgl-project/sglang/pull/42295)), and beam search rejects Mamba models with `--disable-radix-cache` too ([#42354](https://github.com/sgl-project/sglang/pull/42354))\r\n* **The `tc_piecewise` prefill CUDA graph backend is removed.** Passing `--cuda-graph-backend-prefill tc_piecewise` or a `tc_compiler` setting now raises an error; CUDA keeps `breakable` as the default prefill graph backend, and other platforms default to no prefill graph: [#42287](https://github.com/sgl-project/sglang/pull/42287)\r\n* **Renamed and retired environment variables.** `SGLANG_AITER_MLA_DCP_DECODE_BACKEND` becomes `SGLANG_AITER_MLA_DECODE_BACKEND` and its default changes from `gluon` to `asm` ([#34537](https://github.com/sgl-project/sglang/pull/34537)); `SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW` becomes `SGLANG_OPT_RELEASE_PREFILL_SWA` ([#42657](https://github.com/sgl-project/sglang/pull/42657)); the old names keep working with a deprecation warning. `SGLANG_DSPARK_FAST_SAMPLING`, `SGLANG_DSPARK_FOLDED_SAMPLING` and `SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV` are deprecated and no longer do anything ([#43622](https://github.com/sgl-project/sglang/pull/43622), [#43668](https://github.com/sgl-project/sglang/pull/43668)), and `SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE` is deprecated: [#43444](https://github.com/sgl-project/sglang/pull/43444)\r\n* **OpenAI chat responses changed in three small ways.** `tool_choice: \"none\"` no longer shows tool schemas to DeepSeek models ([#43006](https://github.com/sgl-project/sglang/pull/43006)), an absent `tool_calls` field is omitted instead of returned as `null` ([#43027](https://github.com/sgl-project/sglang/pull/43027)), and a stream keeps one `created` timestamp for its whole lifetime: [#43026](https://github.com/sgl-project/sglang/pull/43026)\r\n* **`--enable-layernorm-sp` is rejected with pipeline parallelism.** It failed on the first prefill before: [#43458](https://github.com/sgl-project/sglang/pull/43458)\r\n* **For model and plugin authors:** `ModelRunner.tp_group` is removed; read `get_parallel().tp_group` in the scope the code runs in ([#41817](https://github.com/sgl-project/sglang/pull/41817)).
